# Vyndamax Precision Engagement DX Headroom

This repository contains the source code for the DX headroom and patient-journey analysis workflow.

## Setup

Set the following environment variables before running the scripts:

- SNOWFLAKE_ACCOUNT
- SNOWFLAKE_USER
- SNOWFLAKE_AUTHENTICATOR
- SNOWFLAKE_PASSWORD
- SNOWFLAKE_ROLE
- SNOWFLAKE_WAREHOUSE
- SNOWFLAKE_DATABASE
- SNOWFLAKE_SCHEMA

The scripts intentionally read credentials from environment variables instead of storing them in Git.
